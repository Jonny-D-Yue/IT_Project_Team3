1. Project Overview
EaterAI is a goal-oriented AI agent system designed to help diners make smarter food decisions in restaurants.

The system allows users to:
- Scan QR code at a table
- View menu instantly
- Chat with an AI assistant for recommendations

The AI understands:
- Dietary preferences
- Allergies
- Health goals
- Budget constraints
- Personal cravings

EaterAI acts as a personal food copilot, enhancing the overall dining experience.


2. Problem Statement
Many diners face difficulties when:
- Menus are too large or overwhelming
- They have dietary restrictions or allergies
- They want to track calories or eat healthier

Most current systems:
- Only display static menus
- Do not provide intelligent guidance

EaterAI solves this by combining:
- AI reasoning
- User preferences
- Real-time menu data


3. Project Goals
- Build a full-stack AI-powered restaurant system
- Provide personalized, context-aware food recommendations
- Implement real-time ordering via QR
- Support AI conversation with memory
- Use MongoDB for flexible data storage
- Deliver a mobile-first PWA experience


4. Core Features

Customer Features:
- Scan QR -> access menu instantly
- Chat with AI for recommendations
- Add items to cart & place order
- Voice interaction (planned)

AI Chat Agent:
- Understand natural language 
- Recommend dishes based on preferences
- Explain recommendations

Admin / Waiter Dashboard:
- Manage menu (Add/Edit/Delete)
- View table orders
- Input orders manually
- Checkout system

Kitchen System:
- View incoming orders
- Track order status

Analytics Dashboard:
- Revenue tracking (daily/monthly/yearly)
- Order insights


5. AI Agent Design

Memory:
- Stores conversation history
- Remembers user preferences

Tool Usage:
- Fetch menu from database
- Filter by diet & allergy
- Rank by calories, price, popularity

Planning & Reasoning:
1. Detect user intent
2. Apply constraints
3. Filter valid dishes
4. Rank results
5. Generate explanation

The AI behaves like a smart waiter, not just a chatbot.


6. Technology Stack

Frontend:
- ReactJS
- PWA

Backend:
- Node.js + Express

Database:
- MongoDB (Mongoose)

AI:
- Gemini AI API


7. System Architecture

PWA (ReactJS) --> Node.js (Express API) --> Gemini AI Service --> MongoDB Atlas
